📞 SUPPORT
================================================================================

Q: Làm thế nào để chạy chỉ 1 test case?
A: Bạn có thể comment các test khác hoặc dùng pytest filter.

Q: Test chạy quá lâu?
A: Normal duration là ~0.01s. Nếu lâu, kiểm tra system resources.

Q: Cần chạy test song song?
A: Cài pytest-xdist: pip install pytest-xdist, rồi chạy: pytest -n auto

Q: Báo cáo lưu ở đâu?
A: Trong thư mục docs/, tên: test_report_YYYYMMDD_HHMMSS.txt

Q: Có thể integrate vào CI/CD?
A: Có! Exit code là 0 nếu pass, 1 nếu fail. Perfect cho Git Actions/Jenkins.
